## 段階3で作ったもの

### 帳票の基盤と生成（T29〜T33。ADR-0018〜0022）
- 様式マスタ（`FormTemplate`・`FormMapping`）を、リポジトリのファイル（`templates/forms/`・`mappings/`）から読み込む（`make forms`）。版は `様式ID × 適用開始日 × 言語`。旧版は消さない。
- Excel はシートの XML のセルの値だけを書き換え、Word は差込タグに差し込み、LibreOffice で PDF にする（`convert(path) -> pdf`）。PDF にする一時の写しでだけ変えてよいものは ADR-0032 の例外の一覧（第1-17号の結合、提出書類一覧表の〇・横 1 頁・改頁・表紙の縦の配置、第1-5号〔日中併記〕の詰め方）。
- 生成前の検査（生成不可・警告。不足ごとに直す画面へ）。生成履歴（スナップショット・様式の版・規則・警告）。帳票タブ、署名済みのスキャンの添付、回収のタスク。
- 字体の置き換え（`backend/config/fonts/99-form-fonts.conf`）: ＭＳ 明朝・ゴシック → IPA、ＭＳ Ｐゴシック・游ゴシック → Noto Sans CJK JP、游明朝 → Noto Serif CJK JP、SimSun → Noto Serif CJK SC。

## 開発環境の注意（段階3で増えたもの）

- `make forms` は、生成履歴のある版のテンプレート・マッピングを置き換えない。開発用の DB でテンプレートを直したときは、その版の生成履歴（ダミー・シナリオ）を消してから読み込む（`make seed-scenario RESET=1` や `make seed-reset` の後に `make forms`）。
- 訳文の版は `tools/forms/make_translation_templates.py`、日中併記の版は `tools/forms/make_zh_templates.py`・`make_zh_supplement.py` で作る（手で直さない。テストで同じことを確かめる）。
- 提出用の統合 PDF の容量の上限は `SUBMISSION_PDF_MAX_MB`（既定 25）。
- 道具の中には Python 3.10 以上が要るものがある（ホストの python3 が古いときは `docker compose exec -w /app web python tools/...`）。
