# ADR-0044: 帳簿の出力（外国人ごとの ③④ と機関全体の ①②・月ごとの集計）

- 状態: 採用（T57）。不在の間の指示（2026-10-20・21）により、決めてほしい点はおすすめで決めた（`.checks/phase4/blockD/plan.md`・`.checks/phase4/decisions-blockBCD.md` の T57-D1〜D4）
- 日付: 2026-10-21
- 関連: ADR-0036（帳簿の記載事項・保存期間・今の記録との対応）・0012（支援の期間の定義）・0037（担当者の履歴）

## 背景

ADR-0036 決定 1: 帳簿の出し方は、外国人詳細の「帳簿」の画面（③④）＋外国人ごとの PDF＋機関全体の①②と月ごとの集計（支援人数・行方不明者数・職員数）の xlsx（自作）。出力は監査ログに export で残す。帳簿は電磁的記録でよいが「直ちに整然とした形式及び明瞭な状態で…表示し、書面を作成できる」こと（運用要領 本体 印刷153）。

## 決定

1. **外国人ごとの帳簿の画面**（T57-D1）: 外国人詳細のタブ「帳簿」（操作 support.view）。
   - ③ 支援対象者に関する管理簿: 氏名・生年月日・国籍・地域・性別・在留カード番号（在留情報の最新行。画面を開くと監査ログに閲覧と復号した欄を残す）・雇用する特定技能所属機関・支援計画の版・支援の期間（ADR-0036 決定 3: 雇用契約と全部委託の支援委託契約が重なる期間と終わりの理由）・帳簿の保存義務の満了日（目安）。
   - ④ 支援の実施に関する管理簿: 取り消していない支援実績を日付順に（支援の項目・方法・場所〔記録の詳細の場所、ガイダンスは実施場所〕・担当者と記録のときの役職・通訳人〔ガイダンス・相談・記録の詳細〕・内容〔相談は分類と状態を頭に。200 字まで〕・本人の申出により実施せず）。関係する書類（生成物と署名の状態）。
2. **外国人ごとの帳簿の PDF**（T57-D2）: 同じ内容を自作の xlsx（3 枚のシート）にし、LibreOffice で PDF にしてその場でダウンロードする（保存しない）。監査ログに EXPORT（context の books=worker）。
3. **機関全体の xlsx**（T57-D3）: 設定のタブ「帳簿」（操作 organization.manage）で期間（5 年以内）を選んでダウンロード。シートは ① 支援実施体制（自機関の名称・住所・代表者・法人番号・登録番号・役員・事業所）、① 担当者（氏名・役職・事務所・支援責任者・支援担当者・雇用形態・言語・講習の修了日・有効）、② 支援の委託契約（受入れ機関・締結日・期間・範囲・委託料と内訳・終了の区分）、月ごとの集計（その月に 1 日でも支援の期間がある外国人の数・届出タスク「行方不明」の起算日の数・月末の職員数〔常勤・非常勤〕）。監査ログに EXPORT（books=organization と期間）。
4. **職員数の推定**: 担当者の在籍の履歴を持たないので、今の有効な担当者を登録の日から数える（画面に書いた）。

## 未確認の点

- 帳簿の書式（参考様式が無い）。運用要領の「直ちに書面を作成できる」を、PDF と xlsx の出力で満たすとした。
- 月ごとの職員数の数え方（決定 4 の推定。退職した担当者を過去の月に数えない）。
- 支援経費の収支は会計の帳簿に任せる（ADR-0036 決定 2 のまま。xlsx には委託料と内訳だけ）。
