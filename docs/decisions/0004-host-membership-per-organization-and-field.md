# ADR-0004: 登録法人・協議会への加入は「受入れ機関×分野」で持つ

- 状態: 採用（仕様書 第6章・第7章は本 ADR に合わせて修正する）
- 日付: 2026-10-16
- 関連: 仕様書 第6章「対象分野の上乗せ要件」「システムへの反映」、第7章 host_organizations / host_sites、T08

## 背景

受入れ機関は、分野ごとに次の団体の構成員でなければならない（第6章）。

- 工業製品製造業分野: 経済産業大臣登録の特定技能外国人受入事業実施法人（登録法人）
- 飲食料品製造業分野: 食品産業特定技能協議会

加入日と証明書（構成員証明書・会員名簿の写し）をどこに持つかについて、仕様書の記述が食い違っていた。

| 箇所 | 記述 |
|---|---|
| 第6章「システムへの反映」 | 事業所（host_sites）に、登録法人または協議会の加入日と証明書（添付）を持つ |
| 第7章 host_organizations | 受入れ機関に「協議会加入日」を持つ |

加入は事業所単位ではなく、受入れ機関（法人・個人事業主）単位で行う。事業所に持つと、同じ加入日と証明書を事業所の数だけ登録することになり、片方だけ更新されて食い違うおそれがある。
受入れ機関に分野ごとの列（`food_council_joined_on` など）を持つと、分野を足すたびに列を足すコード変更が要り、「分野はマスタで持ち、追加に備える」方針に合わない。

## 決定

加入は新しいテーブル `HostMembership`（受入れ機関×分野で一意）で持つ。

- 項目: 受入れ機関、分野、加入日、有効期限（空 = 期限なし）、会員番号、証明書（Attachment、種別「受入れ機関の加入証明」）
- 加入先の種類と名称（登録法人／協議会）は分野のマスタ（`SpecifiedSkillField`）に持つ。分野を足すときはマスタに行を足すだけでよい。
- 事業所は自分の分野を持ち、加入の有無は「事業所の受入れ機関 × 事業所の分野」の `HostMembership` で判定する（`services/hosts.is_member`）。
- 受入れ機関・事業所には加入日・証明書の列を持たない。

## 影響

- 仕様書 第6章「システムへの反映」の 1 つ目と、第7章 host_organizations の「協議会加入日」を、本 ADR に合わせて修正する（仕様書の管理者が対応）。
- 生成前バリデーション（段階3、F11）の「加入証明の添付がない場合は生成不可」は、`HostMembership` の添付の有無で判定する。
- 証明書に有効期限があれば `valid_until` に入れ、期限ダッシュボード（T14 以降）で扱える。

## 検討した代替案

- **仕様書 第6章どおり事業所に持つ**: 同じ証明書を事業所ごとに重複して持つ。事業所を足すたびに証明書の再添付が要る。
- **仕様書 第7章どおり受入れ機関に分野別の列を持つ**: 分野の追加に列の追加（コード変更）が要る。工業の登録法人の加入日の置き場所もない。
