# ADR-0042: 様式マスタの管理（F13）— 版の一覧・停止・別の版での作り直し・記入済みの取り出し

- 状態: 採用（T53）。不在の間の指示（2026-10-20・21）により、決めてほしい点はおすすめで決めた（`.checks/phase4/blockD/plan.md`・`.checks/phase4/decisions-blockBCD.md` の T53-D1〜D4）
- 日付: 2026-10-21
- 関連: ADR-0018（生成と変換）・0019（生成前の検査）・0022（署名済みの写し）、仕様書 第5章 F13・第6章「様式のバージョン管理」、`docs/tasks-phase4.md` の D8・D9

## 背景

仕様書 第6章: 様式マスタは「様式 ID × 適用開始日 × テンプレート × マッピング定義」の組。生成のときは基準日で版を自動で選び、担当者が別版を明示的に選ぶこともできる。旧版は削除せず、過去の生成物を同じ版で再生成できる。マッピングはデータで持ち、管理者画面または JSON の取込で更新できる。D8: 新しい版の登録は、リポジトリのデータ（`templates/forms`・`mappings`）と `make forms` を正にする（版の作成には道具とテストが要るため）。画面は一覧・切替・旧版での再生成・記入済みの取り出し。

## 決定

1. **画面**（T53-D1）: 設定のタブ「様式マスタ」（操作 masters.manage。管理者）。様式 ID ごとの版の一覧（名称・適用開始日・改正日不明の印・言語・方式・生成の件数・使用中か停止中か）と、版の詳細（出典の URL・取得日・ADR・元のファイルとテンプレートの SHA-256・マッピングと規則のファイルと欄・規則の数・同じ様式の版）。詳細を開くと監査ログに閲覧を残す。
2. **切替**（T53-D2）:
   - 基準日での自動の切替（`form_templates.select_template`。今のまま）。
   - **版の停止と解除**: 新しい版に不備が見つかったとき、その版を停止すると、基準日がその版の適用開始日の後でも前の版が選ばれる。理由は必須で、監査ログに残す（UPDATE・context の suspended）。同じ様式 ID・言語で停止していない版がほかに無いときは停止できない（様式が作れなくなるため。直した版を先に読み込む）。停止の状態は `FormTemplate.suspended_at`・`suspended_reason`（列の追加。読み込み〔`make forms`〕では変えない）。
   - **版を選んで作り直す**: 生成物の画面で、同じ様式 ID・言語の版（同じ版・旧版・停止中の版も選べる）を選び、生成のときのデータ（スナップショット）で新しい生成履歴を作る（`form_master.regenerate`。`form_generation.request` に選んだ版を渡す）。元の生成履歴は残す。生成前の検査は今の台帳で行い、生成不可があれば作らない（警告は元の生成で確かめたものとして受ける）。
3. **記入済みの取り出し**（T53-D3。D9）: すべての生成物（完了・記入済みのファイルがあるもの）で「記入済み（編集用）」の docx・xlsx をダウンロードできる（T51 で定期届出の 3 様式に先に使った制限を外した）。権限は生成物を見る権限と同じ（forms.generate と外国人を見る権限）。ダウンロードは監査ログに DOWNLOAD・file=filled。一括申請・一括届出の xlsm は ADR-0039・0040 のとおり。
4. **改正の反映の手順と試し**（T53-D4）: 改正はコードを変えずに、次の手順で反映する（運用手順「様式が改正されたとき」に書いた）。
   1. 入管の新しい様式を取得し（URL・取得日・SHA-256・改正日）、`templates/forms/<様式ID>/<適用開始日>/` に original と manifest、`mappings/<様式ID>/<適用開始日>.json`・`.rules.json` を作る（Word は道具で template.docx を作る。一括のツールは道具で columns.json を作る）。
   2. テスト（`make check-quick T=tests/forms_engine`）で欄の対応と生成を確かめ、`make forms` で読み込む。
   3. 様式マスタで新しい版が「使用中」になり、基準日がその後の生成から新しい版が選ばれることを確かめる。不備があれば新しい版を停止する（前の版に戻る）。
   - 試し: テスト `tests/forms_engine/test_form_master.py::test_a_revision_is_reflected_by_data_only` で、第3-6号（別紙2）の新しい版（適用開始日 2027-04-01）を足して読み込み、基準日 2027-03-31 は旧版・2028-03-31 は新版が選ばれること、新版で作った生成物を旧版で作り直せること、新版を停止すると旧版に戻り、読み込み直しても停止が残り、解除で新版に戻ることを確かめた（記録 `.checks/phase4/blockD/t53-trial.md`）。

## 未確認の点

- 「マッピング定義を管理者画面で更新する」（仕様書 第6章）は作っていない（D8 でリポジトリのデータを正にした）。画面での編集が要るかは、価値検証で確かめる。
- 停止した版で作った生成物（停止の前に作ったもの）の扱い（そのまま残す。作り直すかは人が判断する）。
