# ADR-0039: 在留申請オンラインの一括登録用ツールへの書き込み（一括申請）

- 状態: 採用（T47 書き込みの基盤。T48・T49 は追記する）。不在の間の指示（2026-10-20）により、決めてほしい点はおすすめで決めた（`.checks/plan-blockB.md`・`.checks/decisions-blockBCD.md`）

- 関連: ADR-0018（Excel の書き方）・0038（台帳の項目）、`docs/tasks-phase4.md` の D1〜D4

## 背景

在留申請オンラインの一括申請（認定・更新・変更）は、入管の配るマクロつきのブック（xlsm）で行う。担当者が入力シートに 1 人 1 行で値を入れ、マクロ（「選択」→「出力」）が入力チェックをして CSV を作り、その CSV を在留申請オンラインシステムに上げる。ツールが出した CSV 以外は使えない（操作マニュアル 001369283.pdf 53 頁）。システムは値を入れた xlsm までを作る（D1）。

## 決定（T47）

1. **様式マスタへの登録**（T47-D1）: 様式 ID `bulk-coe`（認定）・`bulk-ext`（更新）・`bulk-chg`（変更）、適用開始日 2026-06-04、方式 `xlsm-rows`（新しい方式）。配布の xlsm をそのまま `templates/forms/bulk-*/2026-06-04/original.xlsm` に置く。
2. **列の表**: 道具 `tools/forms/extract_bulk_columns.py` が、ブックの隠しシート「列項目TBL」から、特定技能で使うシート（共通シート・区分V・更新と変更は同時申請）の欄（シート・列・項目名・チェック種別・桁数・桁数一致・必須・業務コード・区切り・改行・特定技能の CSV 列・リスト連動の親・チェック親列と値・CSV ヘッダ名）を `mappings/bulk-*/2026-06-04.columns.json` に書き出す。表示シート制御マスタから特定技能の非表示の列（無い）も読む。表はブックの SHA-256 つきで、読み込み（`make forms`）のときにブックと合っているかを確かめる。欄の対応（データのキー→列）は `2026-06-04.json`（T48）。
3. **選択肢の表**: ADR-0038 の `services/data/immigration_codes.json`（3 本の名前定義から）。手続で違う表は手続ごとに引く。
4. **書き方**（T47-D2。`services/form_xlsm.py`）: 入力シートの 8〜307 行に、表示名をインライン文字列で書く。セルの書式は残す。A 列（行の番号の数式 `IF(COUNTBLANK(…)<>…,ROW()-7,"")`）は数式を残し、計算の結果（人の番号）をキャッシュとして書く（D2）。メニューの在留資格（D15）に「特定技能 Specified Skilled Worker」を書く。ほかのファイル（vbaProject.bin・ActiveX・ブックの構成の保護・シートの保護・隠しの状態・入力規則・名前定義・計算の設定）は 1 バイトも変えない。書く行は 1 回の走査で見つけて組み立て直す（区分V のシートは 3MB、300 人×285 列）。
   - VBA を読んで確かめたこと: 「出力」は、「選択」を押したときの D15・D17 と今の値が同じかを確かめる（Select_Click・output。9656 対応）。そのため担当者はブックを開いた後に必ず「選択」→「出力」を押す。D15 を変えたときのイベントは「主たる活動内容」（D17）を消すだけなので、D15 を書いておいてよい。
5. **入力チェックの写し**（T47-D3。`services/bulk_checks.py`）: 列の表を使い、VBA（mdlChk・mdMain）と同じ条件で確かめる。
   - チェック親列があり、親の値がチェック親値に当たらない列は確かめない（頭の「在」は共通シートの列。親値「｜」で複数、親列「,」で複数、親値が空なら「親が空のとき」）。
   - 文字種（removeChr と同じ文字の範囲）・桁数（桁数一致）・必須（特定技能の CSV 列があるものだけ）・業務コード（表示名がツールの表にある。リスト連動の子は親の値の連動の表）。
   - リスト連動の子に値があり親が空ならエラー（chkParentForChild）。
   - 同時申請は、再入国・資格外活動・就労資格証明の「有」の範囲だけ確かめ、どれも無ければ必須だけ。認定のブックの同時申請は特定技能の CSV に出ないので確かめない。
   - 生年月日の欄は文字種が「半角数字」で、日付としては確かめない（ツールも不詳の 99999999 を受ける）。
6. **元のブックとの一致**（T47-D4）: テストで、書いたブックの中のファイルの名前と順、書いたシート以外のすべてのファイル、書いたシートの書いた行以外の XML が、元のブックと同じことを確かめる。openpyxl は読み戻しの確かめにだけ使う。
7. **300 人を超えるとき**（T47-D5）: 300 人ごとにファイルを分ける（T48）。
