# ADR-0026: 受入れ機関・分野の書類（第3-1号・第13-1号・第13-2号・第5-10号・第1-25号）と申請の書類の一覧

- 状態: 採用
- 日付: 2026-10-18
- 関連: 仕様書 第6章「出力物」「対象分野の上乗せ要件」「受入れ機関固有の書類テンプレート」、ADR-0004（加入）・0011（要配慮添付）・0015（支援委託契約）・0017（委託料と終了）・0018・0021（誓約の照合の考え方）・0023（.doc の様式）、T28c・T37（ブロック B の計画 T37-D1〜D13）

## 背景

在留申請には、外国人ごとの様式（支援計画書・雇用契約の書類）のほかに、受入れ機関・分野ごとの書類（分野の誓約書・加入の証明書）と、登録支援機関に委託する場合の書類（支援委託契約に関する説明書）が要る。どの書類が要るかは、申請の種類（認定・変更・更新）・受入れ機関が法人か個人か・分野・支援の全部の委託か・国籍などで変わる。

ブロック B の計画の調べで、次のことが分かった。

- 生活オリエンテーションの確認書（第5-8号）・事前ガイダンスの確認書（第5-9号）は、現行の提出書類一覧・確認表に無く、運用要領では「保存」の書類である。仕様書 第6章「出力物」とゲート A「手間」は、これらを申請の添付としている（仕様書と食い違う）。
- 支援委託契約書（第5-10号）も、申請の添付ではない（記載例の注記）。
- 第5-10号の第8条（管轄裁判所）と別紙（委託料の内訳）のデータが無い。
- 第1-25号は旧形式の .doc（第1-4号と同じ扱い。ADR-0023）。

## 決定

### 1. 確認書（第5-8号・5-9号）と第5-10号は申請の書類の一覧に出さない（T37-D1）

- 申請の書類の一覧は、提出書類一覧・確認表の行だけを出す。第5-8号・5-9号・5-10号は「保存の書類」で、生成して保存する（帳票タブ・交付記録で扱う）。
- ゲート A の「手間」の書類の組を「書類の一覧で『生成』となる申請の添付一式（1 人分。認定または変更）」に直した（`docs/tasks-phase3.md`）。
- ゲート A の「様式との一致」の一覧から第5-8号・5-9号は外さない（生成して保存する書類として残す）。
- 価値検証（B）に足す予定の項目を「支援計画書と雇用条件書を実申請で使う。確認書は保存の書類として運用で使う」に直した（`docs/tasks-phase2.md`・`docs/tasks-phase3.md`）。

### 2. 申請の書類の一覧（T37-D2・D3）

- 定義はデータ（`application_sets/<coe|chg|ext>/<適用開始日>.json`）。`tools/forms/make_application_sets.py` が入管の Excel の第1〜3表の全部の行（認定 68・変更 76・更新 21）から作り、手で直さない（テストで同じ出力になることを確かめる）。
- 行ごとに、出典の表・番号・書類・要否（○△）・当てはまる条件（法人・個人、工業・飲食、全部委託する・しない、1 年単位の変形労働時間制、国籍）・どう満たすか（生成する様式／添付の種類／システムの外）を持つ。
- 画面は帳票タブの「申請の書類の一覧」。申請の種類と基準日を選ぶ。初期値は在留情報から（無い・認定証明書の行 → 認定、特定技能1号 → 更新、ほか → 変更）。在留期間更新のタスクの詳細から開くと更新。
- 状態: 生成済み（基準日の契約・版を対象にしたもの。署名待ち・署名済みも出す）／ほかの契約・版で生成済み／未生成／添付済み／期限切れ（加入の有効期限）／未添付／システムの外／実績のある機関の書類（第2表の1。システムでは判断しない）／判断できない（基準日の雇用契約が無い）。
- 当てはまらない行も、一覧の下に件数と書類名を出す。
- 健康診断の書類（要配慮。ADR-0011）は有無と日付だけを出す（ファイル名もリンクも出さない）。
- 閲覧は監査ログに 1 件（申請の種類・基準日・表示した生成物の ID）。

### 3. 分野の誓約書の照合（T37-D4・D5）

ADR-0021 の考え方（固定の文が述べる事実と記録が食い違えば生成不可、述べない事実は警告）を当てはめる。

| 様式 | 生成不可 | 警告 |
|---|---|---|
| 第3-1号 | 分野が工業でない・業務区分が分野の区分でない・産業分類が 76 の産業に無い・登録法人の構成員の証明書が無い（期限切れを含む）・作成責任者が空 | 「に限る」の産業・2922（一部だけを除く）・粗いコード |
| 第13-1号 | 分野が飲食でない・業務区分・産業分類が 10 の産業に無い・協議会の構成員の証明書が無い・全部委託なら自機関の構成員証明書が無い・作成責任者が空 | 「に限る」の産業・粗いコード・キャリアアッププランの交付が無い |
| 第13-2号 | 分野が飲食でない・自機関の構成員証明書（加入日と証明書）が無い・作成責任者が空 | 支援委託契約が無い・全部委託でない |
| 第5-10号 | 基準日に支援委託契約が無い | 全部委託でない・終了日が空・内訳が無い・管轄裁判所が空 |
| 第1-25号 | 基準日に支援委託契約が無い・作成責任者が空 | 全部委託でない（「非該当」と書く）・終了日が空・登録番号の形が違う |

- 産業の一覧は `backend/services/data/industries.json`（`tools/forms/make_industry_lists.py` が様式の本文から作る）。「（…を除く。）」は除外のコード、「…に限る」は限定（警告）、「細分類2922…のうち…以外の産業を除く」は 2922 だけを限定として持つ。

### 4. 支援委託契約の書類（T37-D6〜D9・D11・D12）

- 支援委託契約は受入れ機関ごとのまま（ADR-0015）。第5-10号・第1-25号は対象の外国人ごとに、雇用契約を対象に生成する（丙は外国人）。
- 第1-25号の「該当・非該当」は選んだ文字だけを書く。
- 第5-10号の管轄裁判所は自機関の設定（`court_name`）。
- 委託料の内訳（別紙）は支援委託契約の明細（名目・金額・徴収時期〔随時・定期〕。10 行まで）。保存のときに合計が月額と一致することを確かめる。**内訳だけの変更では第3-3-1号を起票しない**（T28c の判定は月額で行う。テストで固定した）。
- 第5-10号の「署名済み添付が必須」は false（事務所に備え置く書類。署名済みの契約書は支援委託契約の添付で持つ）。
- 終了日の無い支援委託契約は警告にして、終了日を空欄で出す。

### 5. 作成責任者（T37-D10）

- 第3-1号・第13-1号・第1-25号は受入れ機関の代表者（役職・氏名）、第13-2号は自機関の代表者を初期値にし、生成の画面で変えられる。変えた値はデータのスナップショットに残る。
- 自機関の設定に代表者の役職（`representative_title`）を足した。第5-10号には作成責任者の欄が無い（甲・乙の記名だけ）。

### 6. .doc の第1-25号（ADR-0023 と同じ）

- original.doc・変換した converted.docx（`tools/forms/convert_doc.py`）・template.docx を置く。変換の前後で頁数・文字・表の作りが同じこと、もう一度変換しても同じことをテストで確かめる。

### 7. 補助用紙・申請人名簿・一括の出力（T37-D13）

- 段階4 に回す。段階3 は 1 人 1 通。

## 影響

- 表の変更: 支援委託契約の内訳 `hosts_supportcontractfee`（新しい表）、自機関に `representative_title`・`court_name`（列の追加。既定は空）。既存の行は変えない。
- 様式マスタは 16 件（5 件を足した）。`make forms` で読み込む。
- **仕様書 第6章「出力物」の変更（仕様書は人が直す）**: 「支援計画書、事前ガイダンス確認書、生活オリエンテーション確認書、報酬の説明書 等 ／ PDF ／ 在留申請オンラインシステムに添付」の行から、事前ガイダンス確認書・生活オリエンテーション確認書を外し、「面談記録書、相談対応記録、支援委託契約書 ／ 社内保管・受入れ機関送付」の行に足す。「申請の添付」の行に、分野の誓約書（第3-1号・第13-1号・第13-2号）と支援委託契約に関する説明書（第1-25号）を足す。
- ダミーデータ: 自機関に代表者（代表理事）・管轄裁判所（東京）、支援委託契約に内訳 2 行（合計 30,000 円）を足した。開発用 DB には `make seed-reset` の後に入る。

## 検討した代替案

- **確認書を「保存の書類（参考）」として一覧に出す**（T37-D1 (b)）: 一覧表に無い行を足すと、出典に忠実でなくなる。
- **一覧に段階3 で扱う行だけを載せる**（T37-D2 (b)）: 段階4 で行を足すときに定義を作り直すことになる。
- **申請の種類を記録から自動で決める**（T37-D3 (b)）: 転職の場合などは決められない。
- **産業分類は警告だけ**（T37-D4 (b)）: 誓約書の固定の文と食い違う書類を出せてしまう。
- **支援委託契約に対象の外国人の明細を足す**（T37-D6 (b)）: 実際の契約の形が確かめられていない。
- **管轄裁判所を契約ごとに持つ**（T37-D8 (b)）: 自機関の契約書の定型の条項なので、設定で足りる。

## 未確認の点

- 支援委託契約を外国人ごとに結ぶか（丙を契約書に書くか）は、実際の契約の形を確かめていない（T37-D6）。
- 工業の会員名簿は、一覧表が「就業場所の名称が掲載されているもの」を求めていて、別冊 25頁の書き方と違う。システムでは確かめられないので、行の留意事項を出すだけにした。
- 第2表の1（適正な受入れ実績のある機関）に当たるかは持っていない。当たる機関は第2表の2・3の代わりに第2表の1の書類を出せる（システムでは判断しない。人の確認待ち）。
- 第3-1号の 2922（自動車用の内燃機関電装品）の扱いは、コードだけでは確かめられないので警告にした。
