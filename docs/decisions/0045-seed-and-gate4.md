# ADR-0045: 段階4のダミーデータと gate4

- 状態: 採用（T55）。不在の間の指示（2026-10-20・21）により、決めてほしい点はおすすめで決めた（`.checks/phase4/blockD/plan.md`・`.checks/phase4/decisions-blockBCD.md` の T55-D1・D2、D-4）
- 日付: 2026-10-21
- 関連: ADR-0038（台帳の項目）・0039（一括申請）・0040（一括届出）、`docs/tasks-phase4.md` の段階4の完了条件 A、`docs/dummy-data.md`

## 決定

1. **seed_dummy に足すもの**（T55-D1。`apps/seed/bulk_builders.py`）: 今の場面（外国人の番号ごとの場面・届出タスク・警告）は変えず、足すだけ。
   - 一括申請の台帳の項目（T46a・T46b）: 自機関の法人番号・登録年月日、事務所の電話、取次者の印、受入れ機関の業種・資本金・決算・申告の版・申請担当者、事業所の常勤職員数と保険、外国人 1・9・25 番の出生地・在日親族・職歴・試験・在留期間のコード。
   - 役員（第1-23号の場面）: 精機工業に、受入れ業務の執行に直接関与しない役員 1 人。
   - 一括届出の場面: 届出タスクの 7 種のうち今のダミーに無い種別（支援計画変更・支援委託契約の変更・行方不明・基準不適合・支援計画の実施困難）を 10〜14 番に手で起票する。
   - 作り直し（`--reset`）は、足した行（試験・役員・申請担当者・申告・決算）を台帳から消す。一括申請・一括届出の行（外国人・届出タスクを参照する）も、台帳の外国人のものなら消す。
   - 開発の DB は作り直さない（不在の間の指示）。作り直す手順は `docs/dummy-data.md` の「段階4の場面」。
2. **住所**: ダミーの住所は架空の市区町村（「サンプル市」など）で、一括申請のツールの都道府県・市区町村の表に当たらない。今の場面を変えないため、seed の住所は変えない。gate4 は、使う外国人・受入れ機関・事業所・自機関・事務所の住所を、表にある市区町村（千葉県船橋市。番地以下はダミー）の住所に直してから作る（担当者が台帳を直す操作に当たる）。
3. **make gate4**（T55-D2。`e2e/test_phase4_gate.py`）: テスト用の DB に seed を入れ、担当者（dummy_tanto）が画面で次を作ってダウンロードし、確かめる。`/admin/` へのリクエストは 0 件。
   - 一括申請 3 種（認定 25 番・更新 1 番・変更〔転籍〕9 番）: 作る → 外国人を追加 → 行の「入力」で保存（申請ごとの入力は services で入れる）→ 不足 0 → Excel を作る → ダウンロード。
   - 一括届出 7 種: 届出タスクの画面の「一括届出に入れる」→ 行の入力（足りない欄は services で入れる）→ 不足 0 → Excel を作る → ダウンロード。
   - ダウンロードした xlsm を読み戻して、写した入力チェック（列項目TBL・業務コードTBL の全規則）を通り、入力シート以外のファイル（vbaProject.bin・ActiveX・ブック・スタイル・名前定義）が元のブックと同じ。
   - `make checks` に `GATE4=1` で足した。
4. **gate4 で見つけたこと**: 一括申請（変更）の「希望する在留期間」の選択肢を「特定技能１号」の頭で絞ると、変更の表（「１年」など）では空になり、画面で選べなかった（T48 の不備。fix 2cff922 で、絞ると空になるときは絞らないようにした）。
