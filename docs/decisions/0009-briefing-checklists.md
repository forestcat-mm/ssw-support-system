# ADR-0009: 事前ガイダンス・生活オリエンテーションは、運用要領の「情報提供しなければならない事項」を版つきのチェックリストで持つ

- 状態: 採用
- 日付: 2026-10-17
- 関連: 仕様書 第5章 F05・F08、第6章「署名を要する書類の扱い」、第7章 support\_records、ADR-0006、ADR-0007、T21、T24、段階3（確認書の PDF）、段階4（一括申請 Excel）

## 背景

T21 では義務的支援①事前ガイダンスと④生活オリエンテーションの実施記録を作る。記録は次の 3 つの用途に使う。

1. 署名済みの確認書（参考様式第5-9号・第5-8号）の元データ（段階3で生成）と、署名済みスキャンの保管
2. 登録支援機関が備えて置く帳簿「支援の実施に関する管理簿」（実施日時・場所・内容・方法・担当者）
3. 事前ガイダンスで確認した「保証金・違約金の契約」と「外国の機関に支払った費用」を、在留諸申請の申請書に写す

情報提供しなければならない事項と所要時間の目安は運用要領で決まっていて、改正されることがある。
チェック項目と時間の基準をコードに書くと、改正の前後で過去の記録の読み方が変わってしまう。

### 未確認の点

- **所要時間の目安と細目は、令和8年8月版（本体）ではなく別冊（令和7年4月1日版）にある。** 本体には「3時間」「8時間」の記載が無い。掲載ページに別冊の令和8年版は無かった。
- **令和8年8月20日の改正の箇所は確かめていない**（新旧対照表を見つけていない）。上の帳簿の項目は現行の本文をそのまま読んだもの。
- **確認書（第5-8号・5-9号）と申請書の改正日は分からない。** 版は URL・取得日・SHA-256 で特定する。
- 根拠条文（特定技能基準省令 第3条第1項第1号イ・ニ・ホ、第4条第2号、上陸基準省令）は別冊の引用で読んだだけで、e-Gov の現行条文とは照合していない。
- 中国語版の更新日と、日本語版との優先関係は分からない（日本語の部分は現行の WORD と同じ文面。読点だけ「，」）。

## 決定

### チェックリストは版つきのデータで持つ

- `backend/services/data/briefing_checklists.json` に版の単位で持つ（版 ID・適用開始日・出典・種別ごとの欄・細目・所要時間の基準）。
- 記録には版 ID を保存する。どの版を使うかは、最初の実施日時の日付で決める（その日以前に適用開始した最も新しい版）。
  改正されたら新しい版を足し、旧版は消さない（過去の記録は旧版の文言・基準で読む）。
- 最初の版の ID と適用開始日は `2025-04-01`（細目と時間の基準の出典である別冊の最終改正日）。
  確認書の改正日が分かったら、この ADR に追記する。

### 欄と細目

- **欄**は確認書の項目で、符号は支援計画の細目（ADR-0006・ADR-0007）と同じ `1.a`〜`1.j`・`4.a`〜`4.f` にする。欄の文言は `support_plan_1-17.json` の `labels` を使う。
  - 事前ガイダンスの `1.j`（支援担当者の氏名・連絡先）は、別冊と第1-17号にはあるが確認書（第5-9号）には無い。チェックの対象には含め、確認書の番号は持たない。
- **細目**は別冊の「情報提供しなければならない事項」の箇条で、符号は `<欄>.<番号>`（例 `4.a.1`）。
  文言は別冊の要約で、別冊の頁をデータに持つ。別冊の【留意事項】で説明を求めている事項（`1.a.2` 危険有害業務の安全衛生、`4.e.4` 緊急速報メール）も細目にする。
  任意的支援（気候・服装など）は細目にせず、本文に書く。
- 細目はすべて必須。細目ごとに「説明した」か「該当なし」（理由は必須）のどちらかを付ける。どちらも付いていない細目が「未チェック」。
- 欄は、配下の細目がすべて「説明した」か「該当なし」のときに完了とする（欄そのものはチェックしない）。
- 細目のチェックは 1 細目 1 行（`BriefingCheck`）で持ち、状態ごとに数えられるようにする。集計（T24）では「説明した」「該当なし」「未チェック」を分けて返す。

### 所要時間

- 実施日時は行（`BriefingSession`: 日付・開始・終了）で持ち、上限は設けない。確認書の欄は 3 行なので、3 行を超えたら「確認書の欄に収まりません」と警告する。
- 支援実績の行（`SupportRecord`）の実施日・開始時刻は最初の行、所要時間は全行の合計にする（一覧と T24 の集計はこれまでどおり支援実績の行を見る）。
- 「同一機関で引き続き雇用し、生活環境に変化が無い」の印は手で付ける。警告は保存を止めない。

| 種別 | 印が無いとき | 印があるとき | 下限（印にかかわらず） |
|---|---|---|---|
| 事前ガイダンス | 180 分未満で「目安の 3 時間を下回っています」 | 警告しない | 60 分未満で「下限の 1 時間に満たないため、適切に行ったとはいえません」 |
| 生活オリエンテーション | 480 分未満で「必要な 8 時間以上を満たしていません」 | 警告しない | 240 分未満で「下限の 4 時間に満たないため、適切に行ったとはいえません」 |

- 別冊の書き方の違い（事前ガイダンスは「3時間程度」、生活オリエンテーションは「少なくとも8時間以上」）を警告の文言に残す。データでは `guideline_kind`（`about`／`at_least`）で区別する。
- 支援計画の実施予定時間（`SupportPlanItem.planned_hours`）を下回るときも警告する。

### 帳簿の項目と、確認書の欄との対応

| 様式・帳簿の欄 | 保存先 |
|---|---|
| 確認書の項目（第5-9号 1〜9、第5-8号 1〜6） | 欄の符号 `1.a`〜`1.i`、`4.a`〜`4.f`（細目のチェックから決まる） |
| 確認書の実施日時（年月日・時分から時分まで。3 行） | `BriefingSession` |
| 確認書の特定技能所属機関（又は登録支援機関）の名称 | 自機関の設定（全部委託だけを扱うため。記載例 ★3） |

| 確認書の署名・署名日 | 署名済み確認書の添付（種別 `pre_guidance_confirmation`／`orientation_confirmation`）と `Briefing.signed_on` |
| 第5-9号の「4 について…将来にわたりしません」 | `Briefing.deposit_contract`（下の表） |
| 帳簿の実施場所 | `Briefing.place` |
| 帳簿の実施方法 | `SupportRecord.method`（生活オリエンテーションだけ「動画視聴（DVD 等）」を選べる。事前ガイダンスは対面・オンラインだけで、オンラインは本人確認の印が必須） |

### 保証金・違約金の契約と、外国の機関に支払った費用（事前ガイダンス）

別冊は事前ガイダンスで「保証金等の支払や違約金等に係る契約を現にしていないこと及び将来にわたりしないこと」と
「支払費用の有無、支払った機関の名称、支払年月日、支払った金額及びその内訳」を確認するよう求めている。
これを構造化して保存し、**在留諸申請の申請書の「外国の機関に支払った費用」欄（正確な見出しは
「外国の機関への費用の支払について、その額及び内訳を十分に理解して合意していることの有無」）と、
保証金・違約金の欄、および段階4の一括申請 Excel で使う想定とする。**

| 保存する値 | 申請書の欄（認定 27・28／変更・更新 22・23） |
|---|---|
| `Briefing.deposit_contract`（`none`／`exists`） | 保証金の徴収その他財産管理又は違約金等の支払契約の有無（有・無） |
| `Briefing.deposit_collector` | 同「徴収又は管理機関名」（有のときだけ） |
| `Briefing.deposit_detail` | 同「徴収金額又は管理財産」（有のときだけ） |
| `Briefing.foreign_fees`（`none`／`paid`） | 外国の機関への費用の支払の有無（支払がある場合だけ、次の欄を記入する） |
| `Briefing.fees_agreed` | 同「額及び内訳を十分に理解して合意していることの有無」（有・無） |
| `BriefingForeignFee.organization_name`（行ごと） | 同「外国の機関名」（複数の行は読点でつないで 1 欄に書く想定） |
| `BriefingForeignFee.amount_jpy`（行ごと、円換算） | 同「支払額（日本円に換算）約＿円」（全行の合計を書く想定） |
| `BriefingForeignFee.paid_on`・`breakdown` | 申請書に欄は無い。別冊の確認事項（支払年月日・内訳）として持つ |

- 事前ガイダンスでは `deposit_contract` と `foreign_fees` の回答を必須にする。`paid` なら費用の行が 1 行以上、`fees_agreed` の回答が必須。
- `deposit_contract = exists` と `fees_agreed = false` は保存できるが、強い警告を出す（上陸基準省令の基準に適合しないおそれ）。
- 申請書のどのセルに書くか（マッピング）は段階4で様式の版ごとのデータとして決める。この ADR では欄の意味の対応だけを決める。

## 影響

- 支援実績の取消は、事前ガイダンス・生活オリエンテーションでも行ごとの取消（理由必須）で、チェック・実施日時・費用の行は残る。訂正は新しい記録。
- T24 は、記録の欄の完了・細目の状態（説明した／該当なし／未チェック）を `services.briefings.summary()` から取る。
- 段階3の確認書の PDF は、実施日時の行が 3 行を超える記録では確認書の欄に収まらない（警告で事前に分かる）。中国語の文言は中国語版の様式から取る。
- 運用要領・様式が改正されたら、新しい版をデータに足し、この ADR に出典を追記する。

## 確認書の生成での扱い（2026-10-18。T32、ADR-0021）

確認書（第5-9号・第5-8号）には、実施日時・所属機関名・説明者の氏名だけを出す。細目の「説明した／該当なし」・費用・保証金は記録（帳簿）に残る。確認書の固定の文が述べる事実と記録が食い違うとき（番号の項目の細目の未チェック、保証金等の契約が「有」）は生成不可、述べない事実（時間・費用の合意など）は警告（ADR-0021 の 2）。
