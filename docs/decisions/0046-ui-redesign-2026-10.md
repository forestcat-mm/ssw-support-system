# ADR-0046: 画面デザインの見直し（2026-10）。トークン・同梱の字体・部品

- 状態: 採用（U1。U2・U3 で骨組みと外国人の詳細を足す）
- 日付: 2026-10-21
- 関連: `docs/design/design-2026-10/design-spec.md`（仕様）と `mock/`（見本）、計画 `.checks/ui-redesign/plan.md`・決めた点 `.checks/ui-redesign/decisions.md`。前の決定は `docs/design/README.md`（Officevibe の読み替え）

## 背景

業務画面のデザインを Claude Design のキャンバスで見直し、仕様と見本の画面 8 つを決めた（2026-10）。前のトークン（濃紺のナビ・明るいコバルトのリンク・ピルの太枠のボタン・クリームの罫線・角 12px）をやめ、白い面と細い枠・藍の強調の 1 色・状態は「色の点＋文字」にする。字体は Noto Sans JP にし、本番は閉じた網で使うので外から読まずに同梱する。

## 決定

1. **トークン**（`backend/apps/core/static/ui/tokens.css`）: 仕様 1〜3 の色・文字の大きさ・余白・角（入力とボタン 6px・パネル 8px・札 999px）にする。役割の変数の名前は残し（`--button-primary-bg` など）、値を入れ替える。`base.css`・`components.css` は役割の変数だけを参照する決まりのまま（`tests/ui/test_layout.py`）。
   - 文字と背景の対比は、使う組み合わせをすべて 4.5:1 以上にし、テストで計算して確かめる（`tests/ui/test_tokens.py`）。
   - 期限のレベル（超過・7日以内・14日以内・対応期間中・受付前）は、塗りの札をやめて「色の点＋文字」（danger・caution・ok・neutral）にする。クラスの名前（`badge--overdue` など）は変えない。
   - 分野の色（工業製品＝ラベンダー・飲食料品＝薄い緑）はやめ、状態の札と同じ細い枠の札にする（U1-D3。色だけで区別しない決まりにも合う）。
   - 影は浮く部品（「…」のメニュー・カレンダー・モーダル・自動ログアウトの知らせ）だけに残す（U1-D4）。
   - 等幅の字体（`--font-mono`）は本文と同じ字体にし、日付・金額・番号は `tabular-nums` で桁をそろえる（仕様 2）。
2. **字体の同梱**（U1-D1・D2 と補い）:
   - Noto Sans JP（400・500・700）: JIS X 0208 の字（第1・第2水準の漢字・かな・記号）と、ASCII・Latin-1・Latin Extended-A・よく使う記号の区画、業務画面の文言（.po とテンプレート）に出る字のサブセット。woff2 で 1 つ約 1.1MB。
   - Noto Sans SC（400・700）: GB 2312 の漢字のサブセット（約 0.95MB）。`unicode-range` を漢字の区画に絞り、JP の字体に無い字（母国語の氏名の簡体字など）だけに当てる。字体の並びは「Noto Sans JP → 端末の和文 → Noto Sans SC → PingFang SC・Microsoft YaHei」。`lang="zh-Hans"` の所は SC を先にする。
   - 置き場所は `static/ui/fonts/`（`fonts.css` の `@font-face`、`font-display: swap`）。ライセンス（SIL Open Font License 1.1）の文 `OFL.txt` と説明 `README.txt` を同じ所に置く。
   - 作り方は `tools/fonts/make_web_fonts.py`（fonttools で可変の TTF から静的な太さを作り、サブセットにする。開発のときだけ使う）。
3. **部品**（`components.css`）: 主ボタン（accent の塗り）・副ボタン（白地・枠。`button--neutral`）・行の中の操作（白地・accent の細い枠。`button--ghost`）・軽い操作（枠なし。新しい `button--light`）・危ない操作（`button--danger`。ふつうは「…」の中）・状態の札（`chip`。`tag`・`status` も同じ形）・状態の表示（`status-dot`）・件数の札（`count`）・タブ（下線 2px）・表（白いパネル・見出しの行・区切りの行 `table__group`）・入力の欄（「必須」の札は danger の小さな札）・セクション（`doc`・`doc-section`・`section-head`・`section-notice`）・項目の並び（`pairs`。横に 2 組、狭い幅で 1 組）・行の並び（`item-row`）。
4. **部品の見本**（`/ui/`）を新しい部品に合わせる。

## 影響

- 画面の見た目が変わる（業務の動き・URL・権限・監査ログ・データは変えない）。e2e は、主ボタンの色を見ていた 1 か所（`test_sign_in`）を直した。
- 静的ファイルが約 5.2MB 増える（字体）。ブラウザは使う太さだけを読み、SC は簡体字を出す画面でだけ読む。

## 未確認の点

- JIS X 0208 に無い人名の漢字（JIS 第3・第4水準など）は、端末の字体に落ちるので字の形が少し変わる（読めなくはならない）。実データで目立つ字があれば、サブセットに足す。
