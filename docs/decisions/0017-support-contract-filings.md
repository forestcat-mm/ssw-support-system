# ADR-0017: 支援委託契約の締結・変更・終了の届出タスクを外国人ごとに起票し、終了は実際の終了日と事由で登録する

- 状態: 採用
- 日付: 2026-10-18
- 関連: 仕様書 第5章 F07、第7章 support\_contracts・filings、ADR-0008、ADR-0015（決定 3・4）、T11、T28a、T28b、T28c、T37

## 背景

特定技能所属機関（受入れ機関）は、登録支援機関との支援委託契約の締結・変更・終了について、事由の日から 14 日以内に届け出る（第3-3-1号・3-3-2号）。
登録支援機関（自機関）は全部委託を受けているので、所属機関が出す届出の漏れを、自機関の期限ダッシュボードで防ぎたい。

T28a までの支援委託契約は、受入れ機関ごとに 1 行＝1 期間（ADR-0015）で、予定の終了日だけを持っていた。
終了の事由・委託料が無く、届出のタスクも起票していなかった。

### 未確認の点

- **自動更新で次の期間に続くこと**（第5-10号 第6条）が、第3-3-1号の「委託契約期間」の変更に当たるか。本体・様式に記述が無い。
- **第3-3-1号の変更事項のうち、委託料・委託契約期間以外**（委託する支援業務・費用の負担・実施状況の報告・倒産等の場合の措置）の扱い。本体の別表に無く、「具体例であり限られない」とだけ書かれている。システムは今の項目に無いので起票せず、必要なときは人が手で起票する。
- 「台帳に載っていて、その受入れ機関と雇用契約がある 1号の人は、全員が自機関の支援の対象」という前提（決定 2）が、実際の契約（第5-10号の丙）と合っているか。外国人ごとの委託は T37 で見直す。

## 決定

### 1. 届出タスクは外国人ごとに起票する

- 種類を 2 つ足す: 支援委託契約変更届出（第3-3-1号）・支援委託契約終了・締結届出（第3-3-2号）。
  - 届出主体は所属機関、区分は入管への届出、期限は事由の日から 14 日（`deadlines.ad_hoc_filing`。ADR-0008）。手でも起票できる。
- タスクの対象は外国人（外国人の「届出」タブと期限ダッシュボードに出る）。
- `trigger_details` に支援委託契約の ID・事由（`concluded`／`changed`／`terminated`）・日付・終了の事由・変更の前後を残す。ダッシュボードの行とタスクの詳細に、第3-3-2号の A／B 欄、変更の内容などの記入の手がかりを出す。

### 2. 対象の外国人

- **前提**: 台帳に載っていて、その受入れ機関と雇用契約がある 1号の人は、全員が自機関の支援の対象とする。外国人ごとの委託（第5-10号の丙）は T37 で見直す。
- 事由の日に、次をすべて満たす人を対象にする（`services/hosts.support_targets`）。
  - その受入れ機関との雇用契約が有効（開始日が事由の日以前で、期間の末日〔版の終了日と終了の登録日の早いほう〕が空か事由の日以後）
  - その日に適用されている在留情報（取り消していない行のうち、許可日が事由の日以前の最も新しい行）の在留資格が特定技能1号
  - 無効化していない
- 2号には支援計画が無いので対象外。在留資格がまだ特定技能でない人（申請中）は、申請の前の事由なので対象外（印刷 100頁）。自機関と受入れ機関の最初の契約は、ふつうは対象者がいないので起票されない。

### 3. 締結・続く行・新しい締結

- **続く行**: 同じ受入れ機関で、前の行に終了の登録が無く、前の行の予定の終了日の翌日に始まる行。
  - 「締結」としては第3-3-2号・第3-2号を起票しない。
  - 委託料が前の行と違うときだけ、第3-3-1号（委託料の変更）を起票する。起算日は続く行の開始日。どちらかの委託料が空なら比べない。
- **新しい締結**: 続く行でない行（最初の行、前の行に終了の登録がある後の行、空白のある行）。
  - 締結日に対象の外国人がいれば、第3-3-2号（B 契約の締結）と第3-2号（別表Ⅲ⑥）を起票する。起算日は締結日。
- 3 つの場合（新しい締結・続く行・終了の登録の後の新しい締結）と空白のある行を、テスト（`tests/hosts/test_support_filings.py`）で固定する。

### 4. 変更（第3-3-1号）

- 既存の行の委託料・開始日・予定の終了日を直すとき、画面で「契約の変更として届け出る（誤りの訂正ではない）」と変更日を選んだ場合だけ、第3-3-1号を起票する。起算日は変更日。
- 誤りの訂正として直したときは起票しない。

### 5. 終了の登録と、実際の終了日

- 終了は「終了を登録」で、実際の終了日（`terminated_on`）・事由の大分類・小分類・その他の文（全角20字以内）を入れる。
  - 大分類と小分類の組み合わせは、第3-3-2号の記載要領の対応表に従う。
  - 実際の終了日は、契約の期間（開始日〜予定の終了日）の中の日にする。
- **予定の終了日（`ends_on`）は残し、実際の終了日を別に持つ。** どちらを使うかは次のとおり。

| 用途 | 使う日付 |
|---|---|
| 期間の重なりの検査（DB の排他制約・`validate_contract_period`） | 期間の末日＝実際の終了日があればそれ、無ければ予定の終了日（`effective_ends_on`。DB は `LEAST(ends_on, terminated_on)`） |
| 今日有効な契約・定期届出の元データ（`active_contract`・`periodic_report`）・受入れ機関の一覧と詳細 | 期間の末日（同上） |
| 続く行の判定 | 前の行の**予定の終了日**の翌日に始まり、前の行に終了の登録が無いこと |
| 内部タスク「支援委託契約の更新」の起算日 | 予定の終了日（T28a のまま） |
| 内部タスクの片付け | 次の行の登録か、終了の登録で完了にする（次の行か終了の登録まで完了にしない。T28a のまま）。終了を登録した契約には、日次の起票で更新のタスクを作らない |

- 終了の登録で、対象の外国人ごとに第3-3-2号（A 契約の終了）と第3-2号（別表Ⅲ⑦）を起票する。起算日は実際の終了日。
- **日次の起票で外国人ごとの要否の確認は起票しない。** 予定の終了日を過ぎても次の行も終了の登録も無い場合は、内部タスク「支援委託契約の更新」に「終了日を過ぎています：次の期間か終了を登録」と表示する（ダッシュボードの行とタスクの詳細）。

### 6. 終了の取消と、元の事由を取り消したときのタスクの扱い（共通の規則）

- 支援委託契約の終了の取消は、管理者だけ（`contracts.reopen`）。理由は必須で、監査ログ（`context.cancel_termination`）に残す。
- **共通の規則**: 元の事由（終了の登録など）を取り消したとき、その事由で起票したタスクは次のとおり戻す（`services/filings.revert_raised_task`）。

| タスクの状態 | 扱い |
|---|---|
| 未着手 | 理由つきで取消にする |
| 対応中 | 残す。`trigger_details.source_cancelled` に印を付け、タスクに「元の事由（…）が取り消されました。このタスクを確かめてください。」と表示する。保存した後のメッセージで件数を知らせる |
| 提出済み・受理済・完了・不要 | 残して、メモに取消の理由を付ける |

- この規則は、支援委託契約の終了の取消（T28c）と、雇用契約の終了の取消（T28b、`services/contracts.cancel_termination`）の両方に使う（2026-10-18 の確認の後に揃えた）。T28a の期限の変更での片付け（期限が早まった・無くなったとき、未着手は取消、対応中は残して知らせる）とも同じ考え方。
- 終了の登録で自動で完了にした「支援委託契約の更新」のタスクは、未着手に戻す（次の行の登録で完了にしたものは戻さない）。
- 取り消すと期間が予定の終了日まで戻るので、その間に別の契約があれば重なりで取り消せない。

### 7. 退職による終了（第3-1-2号で兼ねる場合）

- 雇用契約の終了で起票する雇用契約終了届出（第3-1-2号）のタスクは、事由の日に有効な支援委託契約があれば、`trigger_details` に支援委託契約の ID を残す。
- そのタスクに「第3-1-2号の c 欄（支援委託契約の終了）の記入が要る。この場合、第3-3-2号は要らない」と表示する。
- 退職では第3-3-2号・第3-2号を起票しない。

### 8. 委託料（ADR-0015 の決定 4 の更新）

- 委託料（1 名あたりの月額。第1-25号 第5欄）を支援委託契約に持つ（任意）。
- 別紙の内訳と外国人ごとの委託（丙）は、T37 のまま。

## 影響

- 移行で、支援委託契約に委託料・実際の終了日・終了の事由を足し、期間の重なりの排他制約を実際の終了日つきに作り直した。既存の行は終了の登録なし（今までどおり予定の終了日が期間の末日）。
- 新しい届出の種類 2 つと、事由 3 つ（締結・変更・終了）を足した。
- ダミーデータの支援委託契約に委託料（30,000 円）を入れた。件数とダッシュボードの行は変わらない。
- 雇用契約の終了の取消（T28b）は、当初は取消にできるタスク（未着手・対応中）をすべて取消にしていた。決定 6 の共通の規則に揃えた（対応中は残して印を付ける）。

## 検討した代替案

- **支援委託契約ごとに 1 件のタスクで、対象の外国人を明細に並べる**: 様式が外国人ごとで、外国人の届出タブにも出ない。
- **予定の終了日を過ぎたら、日次で要否の確認のタスクを外国人ごとに起票する**: 登録が遅れているだけの場合にタスクが外国人の数だけ増える。内部タスク 1 件の表示で足りる。
- **終了の登録で予定の終了日を書き換える**: 当初の契約の期間が残らず、続く行の判定と更新のタスクの起算日が変わってしまう。
