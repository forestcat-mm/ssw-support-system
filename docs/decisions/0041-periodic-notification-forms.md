# ADR-0041: 定期届出の第3-6号・別紙1・別紙2 を作る

- 状態: 採用（T51）。不在の間の指示（2026-10-20・21）により、決めてほしい点はおすすめで決めた（`.checks/phase4/blockC/plan.md`・`.checks/phase4/decisions-blockBCD.md` の T51-D1〜D8）
- 日付: 2026-10-21
- 関連: ADR-0012（定期届出の元データ）・0037（担当者の履歴）・0018（Excel の書き方）・0040（一括届出）、`docs/tasks-phase4.md` の D6・D9

## 背景

定期届出（年 1 回。前年4月1日〜当年3月31日の分を、当年4月1日〜5月31日に提出）には一括届出用のツールが無く、電子届出の画面で入力し、第3-6号の別紙1（事業所ごと）・別紙2（署名欄）などを添付する。全部委託の受入れ機関の届出は、登録支援機関の支援実施状況を受入れ機関が取りまとめて、受入れ機関のアカウントで出す（作成要領 001454514.pdf PDF 1〜2 頁・13 頁）。初回の定期届出は 2027年4月（2026年度分）。

## 決定

1. **様式の登録**（T51-D1）: 様式 ID `3-6`・`3-6-1`（別紙1）・`3-6-2`（別紙2）、方式 xlsx-cells（ADR-0018。セルの値だけを書く）、適用開始日 2026-04-01、改正日は不明。署名済みの写しの回収（ADR-0022）の対象にしない（別紙2 の署名は受入れ機関・登録支援機関が紙で行い、スキャンを電子届出に添付する。作成要領 PDF 13 頁）。
2. **生成の単位**（T51-D2）: 受入れ機関×年度。第3-6号と別紙2 は受入れ機関に 1 つ、別紙1 は事業所ごと・5 人ごと（様式の行数）に 1 つ（作成要領 PDF 15 頁「事業所ごとに作成」）。生成履歴の対象は受入れ機関（別紙1 は事業所）、基準日は年度末の 3月31日（支援の形態・担当者の基準日。ADR-0012）。今の生成の仕組み（生成履歴・暗号化のスナップショット・PDF・監査ログ）を使う。
3. **値**（`services/form_data_periodic.py`。元は ADR-0012 の `support_rows` と T45 の担当者の履歴）:
   - 第3-6号: 1 届出対象期間（全角の数字）、2 特定技能所属機関（法人番号の 13 マス、最も多い分野と分野の数、ふりがな、名称、〒・住所、電話）、3 報告対象の人数（台帳の 1号の外国人。2号は台帳に持たないので 0 人）、5 支援の実施状況（全部委託の行が 1 人でもあれば「支援の全部委託あり」に ■）。
   - 別紙1: 機関名・事業所名と、1 人ごとに氏名（ローマ字）・国籍・生年月日・性別（■）・在留カード番号（生成のときに復号）・受入れ分野・支援の形態（3月31日に全部委託なら「登録支援機関に全部委託」に ■ と機関名。そうでなければ空）・支援担当者名と電話（担当者の事務所の電話）・備考（期間中の受入れ開始日・終了日）。
   - 別紙2: 対象期間と受入れ機関名（本文の行）、受入れ機関の名称・法人番号、登録支援機関名・登録番号（自機関。1 機関目の欄）。閉じ括弧の位置は様式のまま全角の空白で埋める。
   - チェックの記号は ■（T31-D6。☑ は置き換え先のフォントに無い）。
4. **給与の欄**（T51-D3）: 第3-6号の 4 労働条件等（平均）・6 備考・担当者・署名と、別紙1 の活動日数・報酬の支給総額・支払方法は、システムに入れない（給与の記録を持たない）。記入済みの xlsx を受入れ機関に渡して記入してもらう。
5. **受入れ開始日**（T51-D4）: 作成要領（PDF 3 頁 ※）は「特定技能」の上陸許可・在留資格変更許可の日。台帳の在留情報に期間中の特定技能1号の許可日があればその日。期間より前に特定技能1号の許可があれば期間中の開始ではない（書かない）。許可日が無ければ雇用契約の開始日で代え、画面に「推定: 要確認」を出す。
6. **随時届出（報告）の提出状況**（T51-D5）: 印は付けない。画面に第4-3号の候補と届出タスクとの照合の結果（ADR-0012）を出し、人が確かめて付ける（必要な報告を出していなければ印と理由書）。
7. **記入済みのダウンロード**（T51-D6。D9 の先行）: 生成物の画面から「記入済み（編集用）」の xlsx をダウンロードできる（権限は生成物を見る権限と同じ。監査ログに DOWNLOAD・file=filled）。この 3 様式から使い、T53 でほかの様式に広げる。
8. **画面**（T51-D7）: 受入れ機関の詳細の「定期届出（第3-6号）」→ 年度を選んで「検査する」（対象の外国人・事業所・担当者・推定の印・第4-3号の候補）→「生成する」→ 生成物の一覧 → 生成物の画面で PDF と記入済みの xlsx。複数の外国人の在留カード番号を含むので、帳票の生成と外国人の閲覧の両方の権限が要る（第5-4号と同じ）。

## 未確認の点

- 報告対象の人数は、台帳の外国人（自機関が全部委託を受けた 1号）だけを数える。受入れ機関が自社支援・ほかの登録支援機関で受け入れている外国人・2号の外国人は数えない（台帳に無い）。受入れ機関に確かめてもらう（運用手順）。
- 受入れ開始日の推定（決定 5）。
- 別紙2 の本文の行（下線のついた空欄）を、下線の無い文字で書き直している。見た目の違いが受付で問題にならないか。
