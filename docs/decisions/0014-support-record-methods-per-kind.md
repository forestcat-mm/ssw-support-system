# ADR-0014: 支援実績の方法は種別ごとに絞り、出入国時の送迎・公的手続への同行は対面で固定する

- 状態: 採用
- 日付: 2026-10-17
- 関連: 仕様書 第5章 F05、第7章 support\_records、T18（支援実績の共通部分）、T19〜T21、ADR-0007

## 背景

T18 では、記録の画面の 6 種別（送迎・住居確保と生活に必要な契約・公的手続への同行・日本語学習の機会・日本人との交流促進・転職支援）のすべてで、方法に対面・オンライン・電話を選べた。
段階2の手間の測定の前の試用で、次の点が分かった。送迎・同行のように、相手のそばで行うしかない支援でも電話・オンラインを選べる。そのため、記録の方法が実際と食い違うおそれがある。

別冊が実施方法をはっきり定めているのは、事前ガイダンス（対面またはテレビ電話等。郵送・電子メールの送信だけは不可。10頁）、生活オリエンテーション（テレビ電話・DVD 等の動画でもよい。19頁）、定期面談（オンラインは互いの表情を確かめられるもの。32頁）だけである。
上の 6 種別に方法の制限は無い。

## 決定

| 種別 | 選べる方法 | 根拠 |
|---|---|---|
| 出入国時の送迎 | 対面だけ（選ばせない） | 送迎そのものが相手のそばで行う支援（12〜13頁） |
| 公的手続への同行 | 対面だけ（選ばせない） | 窓口への同行（21〜23頁）。情報提供は生活オリエンテーションに記録する |
| 住居確保・生活に必要な契約 | 対面・オンライン・電話 | 情報の提供・案内は離れていても行え、同行は対面（14〜17頁） |
| 日本語学習の機会 | 対面・オンライン・電話 | 同上（26頁） |
| 日本人との交流促進 | 対面・オンライン・電話 | 同上（29〜30頁）。情報の提供・案内・参加手続の補助が中心で、日本語学習の機会と同じ形の支援 |
| 転職支援 | 対面・オンライン・電話 | 同上（30〜31頁） |
| 事前ガイダンス・生活オリエンテーション・相談・定期面談 | 変えない（T19〜T21 のとおり） | 別冊の定め（10・19・32頁）に合わせて既に絞っている |

- 種別ごとの方法は `services/support_records.METHODS_BY_KIND`（`methods_for`）に持ち、保存時の検査で合わない方法を弾く。
- 画面は、方法が 1 つだけの種別では方法の欄を対面で固定し、送られた値を使わない。オンラインを選べない種別では、オンライン会議の URL の欄を出さない。
- 「オンライン」はビデオ通話（オンライン会議システム等）、「電話」は音声だけの通話を指す（T18 の選択肢のまま）。
- 送迎・同行を対面だけにするのは、別冊の禁止ではなく自社の方針である（支援の性質から対面以外が考えにくいため）。別冊に方法の定めが加わったら、この表を見直す。

## 影響

- 既存の記録は変えない。新しい規則に合わない記録は、決定の時点で開発用の DB に 0 件（本番は未稼働）。合わない方法の古い記録があっても、表示はそのままで、取消・記録し直しは担当者が判断する。
- 段階3の帳票（支援の記録から作る書類）では、保存した方法をそのまま使う。

## 検討した代案

- **交流促進は対面・オンラインだけにする（当初の案）**: 別冊に電話を除く根拠が無く、同じ形の日本語学習の機会と扱いが分かれるため採らない。
- **方法を自由にしたまま、送迎・同行で対面以外を選んだら警告だけ出す**: 誤りに気づいても記録が残り、集計で食い違うため採らない。
