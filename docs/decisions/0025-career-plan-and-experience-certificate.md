# ADR-0025: キャリアアッププランは受入れ機関×分野の版つきのデータに持ち、実務経験証明書とともに自機関のテンプレートで雇用契約から生成する

- 状態: 採用
- 日付: 2026-10-18
- 関連: 仕様書 第4章（キャリアアッププランの交付）、第5章 F08、第6章「出力物」「署名を要する書類の扱い」、ADR-0010（交付記録）、ADR-0018、ADR-0019、ADR-0022、T22・T36（ブロック B の計画 T36-D1〜D9）

## 背景

飲食料品製造業分野では、キャリアアッププランを雇用契約の締結の前に書面で交付して説明する必要がある。両分野とも、本人の求めに応じて実務経験を証明する書面を交付する必要がある。段階2（T22・ADR-0010）では交付の事実（交付記録）だけを持ち、プランの中身も書類の生成も持っていない。T36 では、プランの中身を持ち、2 つの書類を生成する。

ブロック B の計画の調べで、次のことが分かった。

- どちらも公式の様式が無い（キャリアアッププランは「任意様式」、実務経験証明書は様式の定め無し）。
- キャリアアッププランは申請の添付ではない（交付したことを第13-1号の誓約事項で誓約する）。
- 水産加工業の区分（2027-04-01 から）では、協議会が「転職できる範囲を含むキャリアパスと待遇を説明し、同意を得る」ことを定めている。
- manifest は出典の URL と取得日を必須にしている（自作の様式の扱いが決まっていない）。

## 決定

### 1. プランの持ち方（T36-D1）

- 見出し `CareerPlan`（受入れ機関×分野。事業所ごとに違う場合だけ事業所の見出しで上書きする）。
- 版 `CareerPlanVersion`（追記だけ。適用開始日・変更理由〔2 版目から必須〕・想定されるキャリアルート・転職できる範囲）。
- レベル `CareerPlanLevel`（版ごと。レベル・習熟の目安の年数〔文字。T36-D4〕・業務内容・必要な経験と資格・地位・処遇）。
- 3 つとも監査の対象。版とレベルは作った後に変えない（交付したものを再現できる）。
- 入口は受入れ機関の詳細の「キャリアアッププラン」（作る・新しい版。`hosts.manage`。新しい版は前の版を写して開く）。

### 2. 生成物の対象は雇用契約（T36-D2）

- 契約タブの「キャリアアッププランを作る」「実務経験証明書を作る」から生成する。基準日は画面で入れる。
- 契約に使うプランは、契約の事業所の見出し → 受入れ機関×分野の見出しの順に探し、基準日に適用される版（無ければ最も古い版）。使った版の番号と ID をスナップショットに残す。
- 交付記録（T22）は契約が必須で、未交付の判定も契約ごとなので、対象を契約にそろえる。
- 生成物の画面から交付記録を作れる（キャリアアッププランは「キャリアアッププラン」、実務経験証明書は「実務経験証明書」の種別。契約は生成物の対象の契約。T33 の導線を広げた）。

### 3. 自機関のテンプレート（T36-D3）

- 様式 ID は `career-plan`・`experience-certificate`。版のフォルダに、空の様式（original.docx）と差込タグの版（template.docx）を置く。どちらも `tools/forms/make_own_templates.py` が同じ定義から作り、手で直さない（zip の日時を固定し、同じバイトになることをテストで確かめる）。
- manifest は `source.self_made: true`・`url` は空・`tool`（作った道具）・`retrieved_on` は作った日。読み込みは、自作の様式は URL が空で道具の名前があること、それ以外は URL があることを確かめる。
- レベルの表は 5 行。超えた行は書かずに警告する（T34-D7 と同じ）。

### 4. 水産加工業の区分（T36-D5）

- 版に「転職できる範囲」を持つ。契約の版の業務区分に水産加工業（`fishery_processing`。2027-04-01 から）があり、プランに転職できる範囲が空なら、生成前の警告。
- 交付記録に「転職できる範囲を含むキャリアパスの説明に同意を得た」の印（`consented`。キャリアアッププランだけ）を足した。水産加工業の区分の契約で印が無ければ、交付記録の注意。既存の交付記録の行は印が無いまま（既定 false。表への列の追加だけ）。

### 5. 署名（T36-D6・D7）

- キャリアアッププランの「署名済み添付が必須」は true（受領・説明の欄を置き、T22 の控えの規則と合わせる）。
- 実務経験証明書は false（所属機関の記名だけ）。期間は雇用契約上の期間（最初の版の開始日〜終了の登録の日・期間の終了日・基準日の早い方）で、「休業等の期間を含む」と書く。基準日に契約が始まっていなければ生成不可。

### 6. 工業の契約（T36-D8）と言語（T36-D9）

- 工業製品製造業分野の契約でもプランを作れば生成できる（未交付の警告・不足には使わない）。プランが無ければ生成不可。
- 日本語だけ。中国語は T38。

## 影響

- 既存の表への変更は、交付記録に `consented` の列を足すことだけ（既定 false）。プランの表は新しい表。
- ダミーデータ: 飲食料品製造業分野の事業所を持つ受入れ機関（食品・水産加工）に、受入れ機関×分野のプラン（3 レベル）を足した。工業の受入れ機関にはプランが無い（生成不可の場面）。交付記録の場面（未交付の 9・15 番など）は変えていない。
- 段階3の完了条件 A「様式との一致」の様式の一覧には入れない（公式の様式が無い）。

## 検討した代替案

- **プランを 1 行で上書きする**（T36-D1 (b)）: 交付した内容を後から再現できない。
- **生成物の対象をプランの版にする**（T36-D2 (b)）: 交付記録・未交付の判定が契約ごとなので、つながらない。
- **自作の様式も参考様式と同じ manifest にする**（T36-D3 (b)）: 出典の URL が無いので、読み込みの検査が意味を持たない。
- **年数を数値で持つ**（T36-D4 (b)）: 「5年目以降」などが書けない。

## 未確認の点

- 協議会（食品産業特定技能協議会）独自のキャリアアッププランの様式があるかは、協議会のサイトを取得していないので確かめていない。
- 水産加工業の区分の「同意」の取り方（書面の様式）は、協議会の定めを取得していないので確かめていない。
