# ADR-0008: 期限の期間は民法の期間計算（初日不算入）で数える

- 状態: 採用
- 日付: 2026-10-17
- 関連: 仕様書 第5章 F06・F07、T10（`services/deadlines.py`）、T11、T19

## 背景

期限ダッシュボードとタスクの期限は、「事由が生じた日から14日以内」（随時届出）や
「前回の面談から3か月以内」（定期面談）のような**期間**で決まるものがある。
初日を数えるかどうかで期限が 1 日ずれ、超過の判定と色分けが変わる。

T19 の実装の報告で、定期面談の 7/1 の面談の期限を 10/1 と報告した（テストの期待値を 9/30 と書いて直した経緯がある）。
随時届出の 14 日と定期面談の 3 か月が同じ規則で数えられているかを確かめ、規則を記録する。

## 決定

法令に期間の数え方の特別な定めが無い期間は、民法の期間計算（民法第138条により、ほかの法令の期間にも適用される）で数える。

| 規則 | 根拠 | 実装 |
|---|---|---|
| 初日は算入しない（事由の日の翌日から数える） | 民法第140条 | `deadlines.period_start()` |
| 日で定めた期間は、末日の終了で満了する | 民法第141条 | `deadlines.days_period_end()` |
| 月で定めた期間は暦で数え、最後の月の起算日に応当する日の前日に満了する。応当日が無ければその月の末日 | 民法第143条 | `deadlines.months_period_end()` |

- 日の期間と月の期間は、どちらも `period_start()`（事由の日の翌日）を起点にする。随時届出の 14 日も同じ関数を通す。
- 民法第140条ただし書（期間が午前零時から始まるときは初日を算入する）は使わない。
  事由は日付で記録しており、その日の途中に起きたものとして扱う。
- 末日が休日のとき：
  - **随時届出（入管への届出）**は、行政機関の休日に関する法律 第2条により、次の開庁日まで期限を繰り延べる。
    色分けは安全側として繰り延べ前の日で行う（T10 のまま）。
  - **定期面談（内部のタスク）**は行政機関への手続ではないため、繰り延べない。
  - 民法第142条（休日に取引をしない慣習がある場合の繰り延べ）は使わない。

### どの期限が期間の計算を使うか

| 期限 | 数え方 | 例 |
|---|---|---|
| 随時届出（事由から14日以内） | `days_period_end(事由の日, 14)` → 閉庁日なら次の開庁日 | 9/16 → 9/17 起算 → 9/30。10/3 → 10/17（土）→ 法令上 10/19（月） |
| 定期面談（前回から3か月以内） | `months_period_end(前回の面談日, 3)`。次回の予定日があればその日が期限で、法定の期限は最終期限に残す | 7/1 → 7/2 起算 → 10/1。1/31 → 4/30。11/30 → 2/28（うるう年は 2/29） |

ほかの期限は期間の計算ではないので、この ADR の対象外：
- 在留期限・旅券の有効期限・証明書の有効期限・契約の終了日：その日付そのものが期限。
- 受付・着手の日の前倒し（`add_months`）：業務ルール。
- 定期届出（4/1〜5/31）と登録の更新（満了日の月を基準にした月の初日・末日）：日付が決まっている。

### 定期面談の起算日（T19）

- 起算日は前回の面談日（本人用・上司用の 2 行の早い方）にする。
- 前回の面談が今の雇用契約の開始より前（転籍の前の受入れ機関での面談）でも、前回の面談日のままにする。
  自機関が続けて支援している外国人の「3か月に1回以上」は、転籍で途切れないため。
- 今の雇用契約の開始日を起算日にするのは、面談の記録が 1 件も無いときだけ。

## 影響

- 随時届出の期限は、この変更の前後で同じ日になる（`事由の日 + 14 日` と同じ結果）。数え方を 1 つの関数にまとめただけ。
- 規則はテストで固定する：`tests/test_deadlines.py` の `test_days_and_months_share_the_first_day_rule`・
  `test_months_period_end_follows_civil_code`、`tests/support/test_periodic_interviews.py` の
  `test_daily_keeps_the_last_interview_across_a_job_change`。
- 条文の番号は民法・行政機関の休日に関する法律のもの。入管の届出の「14日以内」、定期面談の「3か月に1回以上」の
  根拠条文（入管法・特定技能基準省令・運用要領）の番号は、この ADR では確かめていない。
