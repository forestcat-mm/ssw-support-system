# 欄に入れる値の訳（中国語・簡体字）の対照表

訳文の版で生成するとき、欄の値が表の文と同じものだけを中国語にする（標準の支援計画の実施予定の初期値・様式の言葉・分野と業務区分・国名など。形の決まった文は正規表現）。ほかの日本語の値（氏名・住所・自由記述）は日本語のまま出す。

> **訳はすべて人の確認待ち**（自作の訳。入管の中国語の様式〔旧い版、001339744.docx〕の訳語を参考にした）。
> 直すときは tools/forms/translations の訳の表（値は backend/services/data/translations）を直し、
> `python3 tools/forms/make_translation_templates.py` で作り直す（この表も作り直される）。
