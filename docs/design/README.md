# 業務画面のデザイン

業務画面のデザイントークンは、**D: Officevibe**（https://styles.refero.design/style/ced1c98f-d489-48f7-a01f-1fa59a07b706）を業務画面向けに読み替えたものを使う。2026-10-16 に、5 つのセット（A: Aboard、B: ElevenLabs、C: Workable、D: Officevibe、E: Glide）を見本画面で見比べて決めた。

- トークン: `backend/apps/core/static/ui/tokens.css`
- 見本画面: 管理者でログインして http://localhost:8000/ui/
- スクリーンショット: [desktop.png](desktop.png)（1366px 幅）、[mobile.png](mobile.png)（390px 幅）。`make design-shots` で撮り直せる（1 倍解像度、ページ全体）

## 選んだ理由

- **構造がわかりやすい**: 左のナビの背景を濃紺にしたことで、ナビと本文の境目がはっきりする。強調の色をコバルト（フォーカス・アクティブ・リンク）だけに絞っているので、いまどこにいるか・どこを押せるかが読み取りやすい。
- **表と合う**: 罫線がすべてクリーム（`#f0e9e1`）で、30 行の一覧でも行の区切りが主張しすぎない。在留期限・在留カード番号・金額の等幅の数字と、警告バッジが目立つ。
- **ボタンとバッジの優先度の釣り合いがよい**: 主要ボタンは濃紺の塗り、警告バッジは低彩度の塗りで、一覧のヘッダーに並べても主要操作と警告の両方が埋もれない。

## 外したセットと理由

- **A: Aboard**: Signal Blue の主要ボタンと、パステルのバッジ（特に Butter）が同じ強さで目を引き、一覧のヘッダーで優先度が並んでしまう。超過のピンク（Blush）が警告として弱く見える。
- **B: ElevenLabs**: 中立ボタン（キャンセル・取り消す）が枠なしの文字だけで、ボタンと気づきにくい。
- **C: Workable**: 7日以内のピーチ（`#fef1e1`）と 14日以内のバター（`#fde8ce`）が、色では見分けにくい。
- **E: Glide**: 構造の区切りの黒い線が、30 行の表やカードの重なりで重く見える。ティールを塗りに使えないため、フォーカスとアクティブの手がかりが弱い。

## 採用にあたって元のセットから変えた点

- **補足の文字**: `#969696` から `#6b6b6b` に濃くした。12px でも WCAG AA の 4.5:1 以上になる（白地 5.3:1、キャンバス `#f9f8f6` 5.0:1、ラベンダー `#eaebf8` 4.5:1）。
- **分野の色**: 2 つの分野を色で分けた。
  - 工業製品製造業分野: ラベンダー `#eaebf8`（文字は濃紺 `#0c1754`）
  - 飲食料品製造業分野: 薄い緑 `#d6ebdf`（文字は `#255639`）。14日以内の色を流用した。
- **業務画面向けの読み替え**: 比較のときから、次の 5 点は全セット共通で読み替えている。
  - 文字の密度: 本文 15px／行間 1.6、表 14px／行高 36px 前後
  - カード: 角丸 12px、余白 16〜24px
  - 見出し: ウェイト 500〜600
  - フォント: system-ui ベースの日本語・中国語のフォント（外部の読み込みなし）
  - 使わないもの: セリフ体のイタリック見出し

## 警告レベルの色

色は閉庁日で繰り延べる前の期限を基準にする。色だけに頼らないよう、必ず文字（「超過 5日」「あと3日」）を併記する。

| レベル | 地 | 文字 | 形 |
|---|---|---|---|
| 超過 | `#f7e0de` | `#862d27` | 塗り |
| 7日以内 | `#f8e5c3` | `#745011` | 塗り・太字・左に印 |
| 14日以内 | `#d6ebdf` | `#255639` | 塗り |
| 対応期間中 | — | `#0c1754` | 濃紺の枠線のみ |
| 受付前 | — | `#6b6b6b` | 日付の文字だけ |

赤・琥珀・緑は、彩度を抑えた色にしている（HSL の色相は赤 4°、琥珀 38°、緑 145°）。地と文字のコントラスト比はどれも 5.9:1 以上。

## 仕組み

- `base.css`・`components.css` は、`tokens.css` で定義する役割の変数（`--button-primary-bg`、`--nav-bg`、`--level-overdue-bg` など）だけを参照する。
  - 色を変えるときは `tokens.css` だけを直す。
  - テストで、参照している変数がすべて定義されていることを確かめている（`tests/ui/test_layout.py`）。
- admin（管理画面）にはテーマを当てない。
