## 開発環境の注意

- **`make seed-reset` は、ダミーの外国人に手で足した記録も消す**。消えるのは、台帳に載ったダミーの外国人に紐づく支援計画・記録・面談・相談・交付・添付・届出タスク。ダミー以外の手入力のデータと監査ログは残る。手で試した記録を残したいときは、`make seed`（作成済みなら何もしない）だけを使う。
- **ダミーの担当者のパスワード**:
  - `dummy_tanto`（佐藤 花子）と `dummy_tanto2`（鈴木 次郎）は、seed ではパスワードを設定しない。
  - 最初は `docker compose exec web python manage.py changepassword dummy_tanto2` のように設定する。パスワードを一度も設定していないユーザーには、パスワードの再設定のリンクを送らない。
  - 初回ログインで TOTP を設定する。2 人とも `--reset` では消えない。
- **`make gate2 DATE=YYYY-MM-DD`**:
  - テスト用の DB に seed を入れて動く（開発用の DB には触らない）。
  - `DATE` を付けると `django.utils.timezone.now` を同じ日数だけずらすので、画面の「今日」も基準日になる。監査ログの発生日時は実際の時刻のまま。
  - 期待値は基準日から `deadlines` で計算するので、日付を変えても書き換えは要らない。
- **コマンドの実行**: Docker の PATH が通っていないシェルでは、`export PATH="$HOME/.docker/bin:$PATH"` を先に実行する。e2e は `docker compose --profile e2e run --rm e2e pytest e2e/...` で 1 ファイルずつ動かせる。
- **入管のサイトからの取得**: `www.moj.go.jp` は、User-Agent の無いリクエストと、続けての取得を 403 で拒む。様式の取得はブラウザの User-Agent を付けて、間をあけて 1 件ずつ行う。
- **翻訳**: 文言を足したら `make messages` で .po を更新し、訳を入れてから .mo をコンパイルする。.po と .mo の両方をコミットする。`tests/test_i18n.py` が未訳と .mo のずれを検査する。
